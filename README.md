Insurance Pool
The Insurance Pool contract is a decentralized insurance protocol built on the Stacks blockchain using Clarity smart contracts.
It enables users to pay premiums into a shared pool to receive coverage against defined on-chain risks, such as protocol failure, liquidation, or asset loss.
Claims are verified and paid out transparently, ensuring fairness, sustainability, and trust in decentralized risk management.

Features
Register and fund a community insurance pool
Deposit STX premiums to gain coverage
Submit claim requests for compensation
Approve or reject claims via DAO or admin validation
Automated claim payouts from the insured pool
On-chain tracking of pool balance, premiums, and payouts
